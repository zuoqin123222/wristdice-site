# 腕上物理骰子 WristDice

Apple Watch 应用的官方支持网站与隐私政策。

- 使用帮助：`index.html`
- 隐私政策：`privacy.html`
- 支持邮箱：`zaqswe321222@gmail.com`

网站使用普通 HTML、CSS 和 JavaScript，不需要构建或后端。

## GitHub Pages

在仓库的 Settings → Pages 中选择 Deploy from a branch，分支选择 `main`，目录选择 `/ (root)`，保存后使用 GitHub 实际生成的网址。

公开网页资源位于根目录和 `assets/`。联系方式集中配置在 `assets/contact-config.js`。
